# YouTube video watcher  
Watch YouTube videos without cookies and no extra distractions. Perfect for showing 3 unskippable ads.

You could use this for like kiosk projects or something, where you just want to show one YouTube video with minimal UI.

It supports most of the YouTube URL's (shorts, embeds, watch (live support too) and youtu.be) or you could only paste or type in the video ID. Also you can type it in the URL: https://yt-watcher.suklaasukkula.dev/VIDEO_ID_OR_URL_HERE. 

More info in my [stardance project page](https://stardance.hackclub.com/projects/64514)!
Languages: HTML, CSS, JS

This was a short fun project. Only AI usage is help with the 404.html file and a bit of debugging.
